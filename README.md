# Algorithm_Cpp

Baekjoon과 Programmers 문제를 C++로 꾸준히 풀고 기록하는 저장소입니다.

프로젝트와 별개로 자료구조와 알고리즘을 직접 구현하는 감각을 유지하려고 계속 문제를 풀고 있습니다.

`C++` `Baekjoon` `Programmers`

## 다루는 주제

`자료구조` `정렬` `이분 탐색` `DFS/BFS` `그래프` `트리` `최단 경로` `그리디` `DP` `문자열` `구현`

문제를 풀 때는 정답만 맞추기보다 조건에 맞는 자료구조를 고르고, 시간·공간 복잡도를 확인하는 쪽에 더 신경 쓰고 있습니다.

풀이 결과는 BaekjoonHub를 통해 계속 쌓고 있으며, 현재도 문제 풀이를 이어가고 있습니다.
