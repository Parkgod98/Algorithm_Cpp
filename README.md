# Algorithm_Cpp

C++ 문제 해결 역량을 꾸준히 유지하기 위해 Baekjoon과 Programmers 문제 풀이를 기록하는 저장소입니다.

단순히 정답 코드를 모으기보다, 문제 조건에 맞는 자료구조와 알고리즘을 선택하고 시간·공간 복잡도를 고려한 풀이를 지향합니다.

## 학습 방향

- C++ 기반 문제 해결 능력 유지
- 자료구조와 알고리즘의 직접 구현 및 활용
- 같은 문제도 더 단순하고 효율적으로 풀 수 있는 방법 비교
- 꾸준한 문제 풀이를 통한 코딩 테스트 감각 유지

## 주요 주제

`자료구조` `정렬` `이분 탐색` `그래프` `DFS/BFS` `트리` `최단 경로` `그리디` `DP` `문자열` `구현`

## 기록 방식

문제 풀이 결과는 BaekjoonHub를 통해 지속적으로 저장하고 있습니다.

최근에도 풀이를 이어가며 문제 제목, 실행 시간, 메모리 사용량과 함께 커밋 기록을 남기고 있습니다.

## Problem Solving

- Language: **C++**
- Platforms: **Baekjoon · Programmers**
- Focus: **정확성 · 복잡도 · 구현 안정성**
- Samsung SW Professional 역량 취득 이후에도 꾸준히 문제 풀이를 이어가고 있습니다.

## 이 저장소에서 보여주고 싶은 것

프로젝트에서 사용하는 프레임워크나 라이브러리와 별개로, 문제를 자료구조와 알고리즘으로 분해하고 C++로 직접 구현할 수 있는 기본기를 꾸준히 유지하고 있다는 점을 기록하는 저장소입니다.
